### Как скачать

1. Нажмите **Скачать ZIP** напротив нужного скилла.
2. Распакуйте архив. Он содержит отдельную папку скилла с `SKILL.md` и вспомогательными инструкциями.
3. Следуйте способу установки, принятому в вашем агенте.

Архив отдельного скилла не содержит записи разработки или материалы тестирования. Автоматические архивы **Source code** на странице релиза и **Code → Download ZIP** содержат весь репозиторий.

Версии закрепляются тегами вида `<имя-скилла>-v<версия>`. Для каждой новой версии публикуется релиз с описанием изменений и отдельным ZIP в Assets.
